# Agents

## Expression Agent Routing | Richard Schreiber | AI Stewardship

---

## Purpose

Four expression agents generate content, copy, and strategy on Richard Schreiber's behalf. This folder is their routing layer: what each one produces, what it must read before producing it, what it may never rewrite, and when it must hand work to a different agent.

An agent that writes without reading the canon does not produce Richard's work. It produces something that resembles Richard's work, which is worse than producing nothing.

## The Read-First Order — Applies to Every Agent

No agent begins generating until it has read, in this order:

1. **[canonical_index.md](../canonical_index.md)** — locked fields, canonical definitions, URLs
2. **[AUTHORITY-CANON.md](../AUTHORITY-CANON.md)** — the complete nine-section canon
3. **The relevant [avatar file](../avatars/)** — confirm who is being written for before writing
4. **The relevant [track file](../tracks/)** — confirm which population and which frameworks apply

Steps 3 and 4 are not optional. Section 5 of the canon sets the test: *would Jen Morgan recognize herself in this?* An agent that has not read the avatar cannot answer that question.

---

## Locked Fields — Universal Rule

A locked field is a canonical definition, framework name, sign-off, or biographical fact recorded in `canonical_index.md` or `AUTHORITY-CANON.md`.

**Locked fields are quoted exactly. They are never paraphrased, summarized, modernized, shortened, or improved.**

This applies identically to all four agents. There is no agent with permission to rewrite a locked field.

---

## The Unpublished Framework Rule

The canon names 32 frameworks. 20 are published. The remaining 12 exist as names only in this repository.

**No agent may generate, infer, reconstruct, or summarize the content of an unpublished framework.** Framework status is stated in each [track file](../tracks/). If a track file marks a framework *Not yet published*, that framework has no canonical text and none may be manufactured.

An invented framework reads correctly, formats correctly, and is not true. That is the exact failure mode this repository was built to prevent.

---

## Verification Standard

Nothing is delivered because an agent reports it delivered. Output is verified against the published state of the repository before it counts as done.

An agent's confirmation that it saved a file is not evidence that the file exists. The repository is the evidence. This applies to all four agents without exception.
